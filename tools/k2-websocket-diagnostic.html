Creality Monitor - connection diagnostic

This page checks one printer's status WebSocket from this browser. It does not scan your network, request the camera, or send print, fan, light, calibration or G-code commands.

Uses ws://<IP>:9999/ and sends only the same 5-second heartbeat used by the Creality Monitor widgets and Stream Deck plugins. Leave this page open for 15 seconds. If Chrome asks for permission to connect to devices on your local network, allow it for this test.

Browser security can hide the exact reason for a failed WebSocket connection. A failed test in Chrome does not by itself prove a printer firmware issue; the iCUE embedded browser and firewall may behave differently. "Socket opened, no messages" means the browser reached the port, but this test did not receive a status frame. Please send back the report and the printer firmware version.
